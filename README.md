# Sales Analysis Dashboard

Interactive sales analysis dashboard built with Power BI, analyzing 10,000 customers and ₺3.4B+ in total sales across Turkey.

## Features

- Product-level sales ranking (White Goods, Electronics, Computer Parts)
- Monthly sales trend analysis
- Regional sales distribution on interactive Turkey map
- Category breakdown with proportional comparison
- Dynamic year & month filtering

## Key Insights

- Electronics leads with ~42% of total sales
- Black Sea region tops regional sales at ₺765M
- Monthly sales fluctuate between ₺265M–292M

## Tools Used

- Power BI
- DAX
- Microsoft Azure Maps

## Dataset

- 10,000 customers
- Sales data for 2022-2023
- Product categories: White Goods, Electronics, Computer Parts
